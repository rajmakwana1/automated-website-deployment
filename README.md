# Automated Website Deployment using AWS, Docker & Jenkins

## Project Overview

This project demonstrates an automated CI/CD pipeline for deploying a
website using GitHub, Jenkins, Docker and AWS EC2.

## Problem Statement

Manual website deployment is time-consuming and can lead to human errors.

The goal of this project is to automate the deployment process so that
changes pushed to GitHub can be automatically deployed to an AWS server.

## Technologies Used

- HTML
- CSS
- Git
- GitHub
- Linux
- AWS EC2
- Docker
- Jenkins
- Nginx

## Architecture

Developer → GitHub → Jenkins → Docker → AWS EC2 → Website

## Learning Objectives

- Understand Git and GitHub
- Learn basic Linux server administration
- Deploy an application on AWS EC2
- Understand Docker containers
- Build a CI/CD pipeline using Jenkins
- Automate application deployment
